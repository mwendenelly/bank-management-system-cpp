# Bank Management System (C++)
A simple console-based bank management system built using basic Object-Oriented Programming concepts in C++.

## Features
- Create an account
- Deposit money
- Withdraw money
- Check balance
- Menu-driven program using switch-case and do-while loop

## Concepts Used
- Classes and objects
- Constructors
- Functions
- Control structures (if, switch, loops)

## Future Improvements
- Account login system
- Account IDs
- File handling
